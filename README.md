# ⚡ مخطط الإنجاز التكيفي (Adaptive Planner) — الإصدار المعياري 2.0

نظام التخطيط والجدولة الذكية القائم على وكيلين متكاملين (Two-Agent Architecture) مع حساب فلكي دقيق لمواقيت الصلاة بالجيزة وهيكلية قاعدة بيانات معيارية منفصلة في Firebase Realtime Database.

---

## 🚀 التشغيل المباشر
- شغلي ملف `run.bat` أو افتحي `index.html` في أي متصفح حديث (Chrome / Edge).
- التطبيق يدعم التثبيت كـ **PWA** على الهاتف أو سطح المكتب بنقرة واحدة على زر "📲 تثبيت".

---

## 🔑 تحديث قواعد Firebase Realtime Database (Security Rules)
تمت إعادة هيكلة القاعدة إلى 4 جداول رئيسية معيارية غير مدمجة:
1. `users/` (إعدادات وحسابات المستخدمين)
2. `taskTypes/` (جدول الأنواع والألوان والأيقونات)
3. `taskHierarchy/` (شجرة المهام: المسار -> الكورس -> الشابتر/اللاب)
4. `dailyPlans/` (الخطط اليومية وحالات الإنجاز لكل تاريخ)

ضعي الكود التالي في تبويب **Rules** في Firebase Console:

```json
{
  "rules": {
    "users": {
      "$userId": {
        ".read": "auth != null",
        ".write": "auth != null && auth.uid === $userId"
      }
    },
    "taskTypes": {
      ".read": "auth != null",
      ".write": "auth != null"
    },
    "taskHierarchy": {
      ".read": "auth != null",
      ".write": "auth != null"
    },
    "dailyPlans": {
      ".read": "auth != null",
      ".write": "auth != null"
    },
    "prayerCache": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
```

## 🌟 الميزات الجديدة في هذا الإصدار:
1. **فصل المهام اليومية بالكامل:** كل مهمة (مواصلات، بودكاست، صلاة عصر، غداء، مذاكرة) في صف منفصل له مدته ونوعه وعلامة صح `✓` الخاصة به.
2. **روابط مباشرة للمراجع:** زر مباشر `🔗 رابط` لفتح الكتب الدينية (PDF)، بودكاست الذكاء الاصطناعي، ولابات الـ ITI.
3. **لوحة التحكم (Dashboard):**
   - إدارة كاملة لجدول الأنواع (`taskTypes`) لإضافة وحذف وتعديل أي نوع مع لونه وأيقونته.
   - متابعة تسليمات اللابات والـ Deadlines مع تنبيه آلي قبل الموعد بيومين.
   - زر إضافة للتقويم `📅 (.ics)` مع Alarm منبه تلقائي + زر تذكير عبر الإيميل.
   - حاسبة تخطيط الكورسات (بالمحاضرات أو الأيام).
4. **تحديد الكورس والشابتر بدقة:**
   - الكورس: يُحدد بعدد المحاضرات أو بعدد الأيام.
   - الشابتر: يُحدد بالساعات والدقائق بدقة.
